# FRAME / SNS Image Studio

문서 명세를 바탕으로 만든 브라우저용 SNS 이미지 편집툴입니다.

## 실행

```bash
npm install
npm run dev
```

브라우저에서 Vite가 안내하는 로컬 주소를 엽니다.

## 지원 기능

- SNS 비율 프리셋과 사용자 지정 캔버스
- 좌측 설정 패널 / 우측 실시간 편집 화면
- 색상, 투명, 이미지 하단 레이어
- 하단 이미지의 블러, 모자이크, 밝기 조절
- 상단 이미지 삽입 및 크기·위치 조절
- 캔버스 경계 자석 맞춤과 오버플로 안내
- PNG 기기 저장
